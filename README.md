Production-ready MERN SaaS application for managing workspaces, clients, projects, tasks, team communication, notifications, email workflows, and AI-powered guidance.

<p>
  <a href="https://task-flow-pro-project-management-cl.vercel.app">
    <img src="https://img.shields.io/badge/Live_Demo-0A66C2?style=for-the-badge&logo=vercel&logoColor=white" alt="TaskFlow Pro Live Demo"/>
  </a>
  <a href="https://github.com/RoyEid/taskflow-pro-saas">
    <img src="https://img.shields.io/badge/Repository-181717?style=for-the-badge&logo=github&logoColor=white" alt="TaskFlow Pro Repository"/>
  </a>
</p>

**Highlights**

- Workspace, client, project, and task management
- JWT authentication with Google and GitHub OAuth
- Email verification, password reset, support, and feedback workflows
- Real-time team chat and notification flows
- Dashboard summaries, PDF export support, and guidance-focused AI assistant
- Docker Compose support for local development
- Deployed with Vercel, Render, and MongoDB Atlas

**Tech Stack:** React, Tailwind CSS, Node.js, Express, MongoDB, Socket.IO, JWT, OAuth, Docker, Vercel, Render
